Agentic AI SF Hackathon — Official Problem Statement
Theme: Building Production-Ready Agentic AI Applications with RocketRide, Butterbase, XTrace, and Photon
The next wave of AI isn't just intelligent — it's operational. Agents that reason, remember, persist data, reach users where they already are, and can be trusted in production. This hackathon challenges you to combine four complementary technologies to build agentic applications that actually ship: powerful pipelines, instant backends, observability, and the messaging infrastructure to put agents in the interfaces people already live on.
Core Challenge
Design and build an innovative agentic application that:

RocketRide: Construct and orchestrate AI pipelines and multi-agent workflows directly inside your development environment.
Butterbase: Build the entire backend (database, auth, storage, AI model gateway) with zero DevOps.
XTrace: Provide a persistent, self-revising memory layer that extracts facts and reconciles contradictions over time.
Photon (Spectrum): Deploy your agent to messaging platforms (iMessage, WhatsApp, Slack, etc.) so users don't need to visit a separate website.
Mandatory Requirements
RocketRide Usage: Use for core data/AI pipelines and workflows; pipelines must be meaningfully connected to logic.
Butterbase Integration: Provision and serve the backend, integrating database, auth, and the AI Model Gateway.
XTrace Integration: Use the Memory API to allow agents to actively write to and read from a persistent history.
Photon Integration: Deliver the agent through at least one real messaging platform (e.g., iMessage, WhatsApp, Slack).
Deep Integration: All four technologies must be woven into the core product experience to avoid disqualification.
Technology Primers
🚀 RocketRide — AI Pipeline Infrastructure in Your IDE
RocketRide is an open-source AI pipeline builder with a high-performance C++ core. Build visually in VS Code and ship to production. It supports 13 LLM providers and multi-agent orchestration.
🧈 Butterbase — Backend for AI Builders
An AI-optimized Backend-as-a-Service. It automates database, auth, APIs, and file storage. It includes an AI model gateway for unified access to GPT, Claude, and Gemini.
🧠 XTrace — One Brain Across Every Tool
A hosted memory platform that extracts durable facts from conversations and tracks artifacts. It automatically revises old beliefs when new information contradicts them.
💬 Photon (Spectrum) — Bring Your Agents to Users
An open-source framework that connects agents to iMessage, WhatsApp, Telegram, and more via a single API. It adapts message structures natively per platform with edge delivery.
